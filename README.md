# GPTA – GenAI-Powered Teaching Assistant

**GPTA** (GenAI-powered Teaching Assistant) is a web-based platform built to assist educators with classroom management, student performance tracking, and automated AI-driven grading and feedback. 

## Project Highlights

- Role-based access for Students, Teachers, and Admins
- AI-assisted grading with misconception detection and real-time feedback
- Student and class performance summarization
- Course and teacher management
- Bulletin board for announcements
- Help request system between students and teachers
- Periodic code snapshots to identify patterns and potential errors
- Real-time student activity tracking for teachers to monitor engagement
- On-demand AI feedback for submitted or in-progress code
- Code snapshot tracking for feedback and analysis
- Analytics and reporting tools
- Graceful shutdown with data persistence
- Serves static frontend assets

## Technology Stack

- **Backend**: Go (Golang)
- **Database**: MySql (GORM ORM)
- **AI Integration**: OpenAI/Gemini/Claude API
- **Frontend**: HTML, CSS, Reactjs (served as static files), Sublime text Plugin
