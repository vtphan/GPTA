Fill-in-the-Blanks

What: Code framework with strategic gaps for students to complete specific portions.

When to Use:

  • Student shows basic syntax understanding but struggles with implementing specific concepts
  • Student appears overwhelmed by starting from scratch
  • Code patterns need reinforcement without rewriting everything
  • Student's code shows they understand the overall approach but miss crucial elements

Step-by-Step Task Guide

What: Sequential breakdown of the solution process into manageable parts.

When to Use:

  • Student doesn't know where to begin
  • Student's code shows haphazard approach without clear sequence
  • Problem requires a methodical approach that isn't obvious
  • Student needs practice in breaking down complex problems
  • Student is trying to solve everything at once and getting lost

Guided Code with Hints

What: Partial implementation with TODO comments and hints about implementation.

When to Use:

  • Student understands concepts but struggles with application
  • Student's code shows they know what to do but not how to do it
  • Student needs targeted practice with specific programming constructs
  • Student is missing key considerations in their implementation
  • Student demonstrates partial understanding but needs direction for completion

Interactive Debugging Guide

What: Code with deliberate bugs or inefficiencies for students to identify and fix.

When to Use:

  • Student has basic implementation skills but poor debugging practices
  • Student's own code has similar bugs to those in the guide
  • Student needs practice with code reading and understanding
  • Student struggles with identifying logical errors
  • Student can write code but doesn't test edge cases

Progressive Enhancement

What: Series of incrementally more complex versions of a solution.

When to Use:

  • Student needs to see how solutions evolve and improve
  • Student struggles with refactoring and improving code
  • Student has mastered basics but needs challenges to advance
  • Student's code works but is inefficient or lacks sophistication
  • Student tends to stop at the first working solution without considering improvements

Decision Framework

Student Observation Recommended Scaffold
Cannot start or freezes when facing blank editor Step-by-Step Task Guide
Has conceptual understanding but syntax issues Fill-in-the-Blanks
Writes disorganized code without clear structure Step-by-Step or Guided Code
Makes consistent logical errors Interactive Debugging
Implements basic solutions but lacks optimization Progressive Enhancement
Shows partial progress but gets stuck at specific points Guided Code with Hints
Confuses language features or API usage Fill-in-the-Blanks or Guided Code
Writes code that passes simple cases but fails edge cases Interactive Debugging
